    01 D1 · D2 · D5

    Multi-Tool Agent

    Build an agent loop with 3–4 tools, at least two with overlapping intent, structured errors, and an explicit escalation path.

    Deliverable

    Agent-loop code + tool schemas + two failure cases + an escalation decision log.

    Acceptance criteria

    • tool_use/end_turn handled explicitly
    • mandatory business invariant enforced programmatically
    • error carries category/retryability/context
    • ambiguous request triggers the correct clarification/escalation path
    02 D3 · D2

    Claude Code Team Workflow

    Configure a real repository with CLAUDE.md, conditional rules, a reusable skill/command, and MCP integration.

    Deliverable

    Minimal repository diff + two task examples demonstrating scope-specific instruction loading.

    Acceptance criteria

    • global rules are not duplicated across subdirectories
    • path-specific conventions load only where needed
    • shared workflow is version-controlled
    • complex change is explored/planned before edits
    03 D4 · D5

    Structured Data Extraction

    Build an extraction pipeline with schema-constrained output, semantic validation, retry-with-feedback, and partial-failure handling.

    Deliverable

    Schema + 10 test documents + validator + per-document failure report.

    Acceptance criteria

    • required/optional/null semantics are distinct
    • semantic validation is separate from JSON syntax
    • retry receives the specific validation error
    • successful documents are not reprocessed because one item failed
    04 D1 · D5

    Multi-Agent Research

    Design a coordinator + 2–3 subagents for research with explicit coverage, error propagation, and provenance checks.

    Deliverable

    Task decomposition + subagent contracts + synthesis output with source attribution and explicit gaps.

    Acceptance criteria

    • decomposition covers every requested dimension
    • subagent receives sufficient context
    • partial failure returns usable results + gap
    • synthesis does not hide missing coverage
