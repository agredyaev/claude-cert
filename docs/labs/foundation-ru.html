    01 D1 · D2 · D5

    Multi-Tool Agent

    Соберите agent loop с 3–4 инструментами, минимум двумя похожими по назначению, structured errors и обязательной эскалацией.

    Результат

    Код agent loop + tool schemas + два failure cases + журнал решения об эскалации.

    Критерии

    • tool_use/end_turn обрабатываются явно
    • обязательный business invariant enforced программно
    • ошибка несёт category/retryability/context
    • неоднозначный запрос приводит к корректной clarification/escalation
    02 D3 · D2

    Claude Code Team Workflow

    Настройте реальный репозиторий: CLAUDE.md, conditional rules, reusable skill/command и MCP integration.

    Результат

    Минимальный repo diff с конфигурацией + два примера задач, где разные правила загружаются по scope.

    Критерии

    • общие правила не дублируются по подпапкам
    • path-specific conventions грузятся только где нужны
    • shared workflow version-controlled
    • сложная задача сначала исследуется/планируется
    03 D4 · D5

    Structured Data Extraction

    Постройте extraction pipeline со schema-constrained output, semantic validation, retry-with-feedback и обработкой partial failures.

    Результат

    Schema + 10 тестовых документов + validator + failure report по каждому неуспешному документу.

    Критерии

    • required/optional/null semantics различаются
    • semantic validation отделена от JSON syntax
    • retry получает конкретную validation error
    • успешные документы не перерабатываются из-за одного failure
    04 D1 · D5

    Multi-Agent Research

    Спроектируйте coordinator + 2–3 subagents для исследования, где coverage, error propagation и provenance проверяются явно.

    Результат

    Task decomposition + subagent contracts + synthesis output с source attribution и отмеченными gaps.

    Критерии

    • decomposition покрывает все requested dimensions
    • subagent получает достаточный context
    • partial failure возвращает usable results + gap
    • synthesis не скрывает missing coverage
